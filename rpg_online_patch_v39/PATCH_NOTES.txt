TRPG Online v31 - 勢力外交／NPC 自動態度／分支任務／商店聲望折扣
===============================================================

本版接續 v30，重點是讓勢力、NPC 態度、商店與任務分支真正互相影響。

【1. 勢力外交關係】
- 新增 faction_relations。
- DM 可設定「勢力 A → 勢力 B」關係值 -100～100。
- 可自訂關係名稱與備註，例如：同盟、停戰、敵視、世仇。
- 玩家勢力頁會顯示已公開的外交關係。
- NPC 態度計算會參考其所屬勢力與玩家主要聲望勢力之間的外交關係。

【2. NPC 自動態度】
- NPC 對每名玩家會依以下資料自動計算態度：
  - 好感
  - 信任
  - 恐懼
  - 敵意
  - 玩家對 NPC 所屬勢力的聲望
  - 勢力外交關係
- 態度分為：友善／親近／中立／戒備／敵對。
- 玩家與 NPC 互動時會直接看到目前態度。
- 對話造成的關係變化會立即重新計算態度。
- NPC 進入敵對態度時會拒絕交易。
- NPC 商店可額外設定「最高敵意」，超過門檻即拒絕交易。

【3. NPC 商店聲望折扣】
- 商品可指定一個「折扣依據勢力」。
- 可設定：
  - 每 100 聲望折扣幾 %
  - 最高折扣 %
- 玩家商店會直接顯示原價、折扣後價格與折扣百分比。
- 實際扣款由後端重新計算，不只依賴前端顯示。
- 房間獨立庫存、好感門檻、勢力門檻與遊戲幣解鎖規則全部保留。

【4. 任務分支／互斥路線／多結局】
- 任務新增：
  - 分支群組
  - 分支名稱
  - 互斥群組
  - 結局標籤
- DM 可建立例如：
  「相信保全」與「相信醫生」兩條互斥任務路線。
- 玩家完成互斥群組中的其中一條後，同群組其他任務會對該玩家自動鎖定。
- 已完成任務不會被反向覆蓋成鎖定。
- 任務卡會顯示分支名稱與結局標籤。
- 玩家若被分支鎖定，任務會直接顯示原因且不可接受。

【5. 相容性】
- 舊勢力資料無需重建；沒有外交關係時視為中立。
- 舊 NPC 商品沒有折扣設定時維持原價。
- 舊任務沒有分支資料時保持原本流程。
- 保留 v30 之前的大道、信仰、諸神殿、自訂輪盤、戰鬥、探索、理智、時間扭曲、規則怪談、召喚物、裝備、職業等系統。

【測試狀態】
- server.js 已通過 Node.js 語法檢查。
- public/index.html 內嵌 JavaScript 已通過 Node.js 語法檢查。
- ZIP 完整性已檢查。
- 尚未進行正式多人實機全流程測試。
v32：職業能量上限公式

v32.1 修正：補回角色背包使用的 itemTemplateByName 查詢函式，避免開啟角色頁時出現 ReferenceError。

- 職業特殊資源新增「固定上限」與「屬性公式上限」。
- 可選力量、敏捷、體質、精神或幸運，設定倍率與固定加值。
- 例如精神 35、倍率 2、固定加值 0，能量上限會自動成為 70。
- 角色屬性變動後，重新讀取角色資料便會重新計算能量上限。
- 目前能量若超過新上限，後端會自動壓回新上限，避免出現 70 / 50。
- 玩家角色卡、DM 角色檢視及房間成員資料都使用後端計算後的真正上限。
- 舊職業資源沒有設定公式時，仍使用原本固定最大值，無須重建資料庫。
v33：技能職業能量計算公式

- 技能的職業資源操作新增固定數值、資源上限百分比、角色屬性公式三種模式。
- 百分比模式會依後端認定的真正資源上限計算，並向上取整。
- 屬性公式可選力量、敏捷、體質、精神或幸運，設定倍率與固定加值。
- 能量不足時後端會拒絕使用技能，不會先執行技能再扣除。
- 技能卡會直接顯示公式，例如「靈力：消耗 最大值的 20%」或「靈力：消耗 精神 × 0.5 + 5」。
- 舊技能沒有計算模式時仍視為固定數值，無須修改舊資料。
v34：職業能量恢復規則

- 每完整回合可使用固定增減、資源上限百分比或角色屬性公式。
- 戰鬥開始、戰鬥結束與休息都可分別設定：保持、回滿、歸零、固定值或上限百分比。
- 自動與手動結束戰鬥都會套用戰鬥結束規則。
- DM 在非戰鬥狀態可按「休息恢復」，一次套用房間內所有玩家的職業能量規則。
- 所有恢復與扣除都由後端限制在資源上下限內。
- 舊設定的「戰鬥開始重置」與「每回合固定變化」仍可繼續使用。
v35：角色基本資料

- 角色卡新增性別、年齡、身高（cm）與生日。
- 玩家可在「修改角色卡」自行填寫或更新基本資料。
- DM 可在管理員角色編輯器查看與修改這四個欄位。
- 角色卡基本資料區會直接顯示；未填寫時顯示「未設定」。
- 啟動時會自動新增資料庫欄位，舊角色不需重建。
v35.1 修正：補回狀態模板頁、道具模板頁及道具類型名稱函式，修正點擊兩個管理分頁時無法開啟的問題。
v35.2：全站大型數值支援

- 啟動時自動將 public schema 中所有非 ID 的 INTEGER 欄位升級為 BIGINT。
- 角色屬性、HP、精神、理智、大道／信仰、貨幣、怪物／NPC 數值、聲望及其他整數資料都可超過 21 億。
- 支援 100000000000 等大型數值；JavaScript 安全精確範圍仍以 9,007,199,254,740,991 為上限。
- 主鍵、流水號與外鍵不變，不會破壞現有資料關聯。
- migration 可重複執行，已是 BIGINT 的欄位會自動略過，舊資料不需重建。
v35.3 修正：補回 gearLoadout 相容函式，修正玩家點擊「修改角色卡」時編輯視窗無法開啟的問題。
v35.4 修正：補回玩家 wheelsHTML 輪盤頁，包含輪盤圖、選項、伺服器抽取結果、轉動動畫與重新整理功能。
v36：玩家大道／信仰上限權限

- 東國玩家可在角色卡修改大道上限，西國玩家可修改信仰上限。
- 目前剩餘值在玩家編輯器中只讀，不能提交修改。
- 後端拒絕玩家修改不符合陣營的第五屬性，亦不接受目前值欄位。
- 新上限若低於目前剩餘值會拒絕儲存，確保調整上限不會暗中改變剩餘值。
- DM 權限不變，仍可管理上限與目前值。
v37：手機版與應用程式圖標

- 手機底部導覽列支援水平滑動、項目吸附，切換頁面時會自動把目前分頁移到可視範圍。
- 手機表單使用至少 16px 字級與 44px 觸控高度，減少 iPhone 輸入時自動放大並改善點擊。
- 管理分頁可水平滑動，避免大量分頁在窄螢幕擠成多行。
- 手機彈窗改為全螢幕，操作按鈕會停留在底部，長表單較容易編輯。
- 加入瀏海、圓角螢幕及 iPhone 底部安全區適配。
- 加入 PWA manifest、Service Worker、favicon、Android 192／512 圖標及 Apple 主畫面圖標。
- 網站透過 HTTPS 部署後，可從瀏覽器的「加入主畫面／安裝應用程式」使用獨立視窗開啟。
- v37 圖標更新：改用紫色魔法二十面骰原創圖標，並補上 32px 瀏覽器 favicon。
v38：自動回歸檢查與版本辨識

- 新增 release-check.js，可用一條指令檢查伺服器、前端腳本、CSS、manifest、圖標與核心相容函式。
- 自動核對前端靜態 API 呼叫是否存在對應後端路由，並檢查重複路由。
- 自動檢查所有 /api/admin 路由均使用 adminAuth，以及一般 API 的登入保護。
- 固定檢查玩家只能修改所屬陣營的大道／信仰上限，不能提交目前剩餘值。
- 固定檢查角色基本資料 migration、全站 INTEGER → BIGINT migration 與近期修復函式。
- 可用 --zip 檢查壓縮包完整性、殘留檔案、路徑安全及 ZIP 內容與來源雜湊。
- 可用 --db 對已部署 PostgreSQL 執行唯讀 schema 檢查；不會修改資料。
- /api/health 新增 version: "38"，前端亦加入 application-version，方便確認實際部署版本。
- 首次執行檢查時發現舊 `/api/admin/status` 只有登入驗證，已補上 adminAuth，確保 admin 命名空間全部需要 DM 權限。
v39：備份、還原與管理操作紀錄

- DM 管理中心新增「備份／紀錄」分頁，可下載全站、指定房間或指定角色的 JSON 備份。
- 所有備份都帶有 SHA-256 校驗碼；匯入時會拒絕損壞、遭修改、格式不符或目標不一致的檔案。
- 房間與角色採兩階段還原：先預覽影響範圍，再輸入指定確認文字；短效還原許可會綁定操作者、目標與校驗碼。
- 還原前會自動建立安全存檔；還原失敗時資料庫交易會回滾，不留下半套角色資料。
- 備份中心會列出最近 30 筆角色自動安全存檔，可再次預覽並用相同的兩階段流程還原。
- 角色備份包含角色卡、狀態、大道、信仰、聲望、線索、規則情報、道具鑑定與任務狀態；不改帳號密碼或房間資格。
- 房間備份沿用既有狀態回溯機制，只回復仍存在的房間結構；已刪除的地圖、怪物等資料不會被重新建立。
- 全站封存永遠排除密碼、Token、JWT 密鑰、資料庫網址等憑證；為避免誤覆寫，網站介面不提供全站還原。
- 自動記錄所有 DM 管理新增、修改、刪除、備份與還原操作，只保存動作、目標、HTTP 結果及耗時，不保存表單原文或登入憑證。
- 備份介面在手機上使用單欄卡片與可換行紀錄，避免寬表格造成橫向溢出。
- 發版檢查新增備份校驗、憑證排除、兩階段確認、自動安全存檔、全站還原禁用與稽核表／端點契約。
