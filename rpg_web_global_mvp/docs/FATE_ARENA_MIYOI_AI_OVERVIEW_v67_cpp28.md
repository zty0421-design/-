# TRPG Online 67-cpp.28：命鬥場完整 1v1／彌夜 AI 記憶

## 本版內容

- 命鬥場從「只建立等待房」擴充為可實際遊玩的 1v1 非致死 PvP。
- 支援普通決鬥與命運決鬥；命運決鬥由大阿爾克那成為戰場規則。
- API：建立、公開列表、查看、加入、離開、開始、攻擊／防禦、投降。
- PvP HP 儲存在 `fate_gap_pvp_matches.state`，不修改跑團真實 HP。
- 目前將戰車、正義、惡魔三張牌接入基礎 PvP 數值規則，其他牌保留資料驅動擴充位置。
- 彌夜沿用既有 `npc_relationships`，把命鬥場建立、加入、勝利、投降寫入長期記憶。
- 新增彌夜 AI 狀態 API：好感、信任、興趣、厭煩、心情、是否願意參戰／透露秘密。
- 命隙頁新增命鬥場列表、對局操作、HP／回合紀錄與彌夜 AI 狀態。
- 手機版沿用既有 responsive card/layout，不另建立桌面限定介面。

## 安全／一致性

- 對局建立與操作均由 C++ 驗證房間權限、參與者、回合順序與狀態。
- 前端不能指定命運牌結果、傷害結果或勝負。
- 1v1 對局使用獨立 state，不會改寫角色在正式副本中的 HP。
