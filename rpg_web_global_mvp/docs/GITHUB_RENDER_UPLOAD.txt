TRPG C++ Render 根目錄平鋪上傳版

用途：GitHub Repo 根目錄直接放所有檔案，不需要 src/、include/、public/、db/ 子資料夾。

Render 設定：
- Branch: main
- Root Directory: 留空
- Dockerfile Path: ./Dockerfile
- Docker Build Context Directory: .
- Health Check Path: /api/health

必要環境變數：
- DATABASE_URL
- JWT_SECRET（至少 32 字元）
- ADMIN_USERNAME
- ADMIN_PASSWORD

上傳方式：
1. 解壓 ZIP。
2. 打開 rpg_web_global_mvp 資料夾。
3. 將「資料夾裡面的所有檔案」上傳到 GitHub Repo 根目錄。
4. 不要在 GitHub Repo 裡再建立 rpg_web_global_mvp 子資料夾。
5. Render Root Directory 保持空白。
