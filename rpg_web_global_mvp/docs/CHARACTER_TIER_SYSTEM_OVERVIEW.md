# 角色正式等階系統總覽｜64-cpp.25.1

## 1. 等階結構

角色採 **0～10階**；1～10階每個大階分為 **1～4級**。

- 0階：未登階。
- 1～8階：一般登階階段。
- 9階：偽神。
- 9階4級：半神。
- 10階：真神。

0階升1階不需要儀式。角色在任一大階達到4級後，不能直接跨到下一階，必須完成對應儀式。

## 2. 登階規則

```text
0階 → 1階1級：直接晉升
1階1級 → 1階2級 → 1階3級 → 1階4級
1階4級 → 完成登階儀式 → 2階1級
...
8階4級 → 完成登神儀式 → 9階1級（偽神）
9階4級（半神）→ 完成登神儀式 → 10階1級（真神）
```

C++ 會在儀式扣材料前驗證：主持角色是否正好位於來源大階4級、儀式目標是否為下一個大階、儀式類型是否正確。

## 3. 每個大階固定基礎屬性總額

| 大階 | 總基礎屬性點 | 相較前階增加 |
|---:|---:|---:|
| 0 | 0 | — |
| 1 | 50 | +50 |
| 2 | 100 | +50 |
| 3 | 180 | +80 |
| 4 | 320 | +140 |
| 5 | 600 | +280 |
| 6 | 1100 | +500 |
| 7 | 2000 | +900 |
| 8 | 3600 | +1600 |
| 9 | 6500 | +2900 |
| 10 | 10000 | +3500 |

這是**該大階的總額**，不是每個小級再發一次。

## 4. 五項可分配基礎屬性

- 敏捷
- 力量
- 體質
- 精神
- 大道／神明（東國使用大道，西國使用神明／信仰）

任何時候都必須符合：

```text
敏捷 + 力量 + 體質 + 精神 + 第五基礎屬性 + 剩餘基礎屬性點
= 目前大階固定總額
```

玩家不能透過任務或舊式自由獎勵突破這個總額。

## 5. 特殊／衍生屬性

- 幸運：特殊屬性，普通方式不可加點；由出生、物種與特殊效果決定。
- 生命上限：`體質 × 2`。
- 耐力：`floor((體質 + 精神) / 2)`。
- 理智上限：`floor(精神 × 1.2)`。
- 意志：`floor(精神 × 0.8)`。

## 6. 跨階後屬性處理

跨階不會重置已分配屬性。例：

```text
1階4級
已分配：40
剩餘：10
總額：50

完成1→2登階儀式
↓
2階1級
已分配：40
剩餘：60
總額：100
```

## 7. 登階／登神儀式配方

儀式配方可設定：

- `ritual_type = 登階儀式` 或 `登神儀式`
- `ascension_from_tier`
- `ascension_to_tier`
- 材料、元素、佈置、步驟、成功／失敗效果

目標大階必須正好是來源大階 +1。進入9階與10階必須使用登神儀式。

## 8. DM 與玩家操作

- DM：可使用「推進小級／0→1」按鈕。
- 本階未滿4級：每次推進 +1小級。
- 本階4級：按鈕不會直接跨階，會要求完成登階／登神儀式。
- 玩家：自行分配五項基礎屬性，但不可修改幸運或直接改角色大階。

## 9. 相容與防超額

- migration 會把合法舊角色的剩餘點數校正為目前大階固定總額。
- 舊任務若仍保存 `rewards.attribute_points`，完成後不再提高總額；C++ 會重新依大階額度校正剩餘點數。
- 若舊角色已分配屬性本身超過目前大階總額，不會自動砍屬性，需由 DM 校正。
