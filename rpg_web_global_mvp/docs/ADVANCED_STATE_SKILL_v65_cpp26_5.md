# 65-cpp.26.5 進階形態／階段技能

此系統把「特殊資源 + 區間階級 + 形態轉換 + 屬性轉換 + 特殊退出條件」做成技能模板資料，不需要為每個角色另外寫死 C++。

## 可編寫欄位

- 自訂資源：名稱、Key、初始值、最小值、上限。
- 戰鬥開始重置：可指定第一輪開始時回到初始值。
- 啟動門檻：資源低於門檻時不可切換形態。
- 階級區間：每一階以最小～最大值定義，不要求精確值。
- 形態：原形態、轉換形態、必要媒介／道具。
- 屬性轉換：`增加量 = (原屬性 - 轉換後屬性) × 倍率`。
- 理智倍率：作用於形態中的最終精神值；退出後隨精神恢復。
- 極限階：可分別設定「資源歸 0」與「主動退出」是否觸發下一回合懲罰。
- 下一回合懲罰：不可行動、不可被選中可獨立開關。

## 血淚值 V1.1 範例

- 初始值 40，上限 120，每次戰鬥第一輪重置為 40。
- 80～99 = 80%階；100～119 = 100%階；120 = 120%階。
- 啟動最低值 80。
- 原形態：黃泉擺渡人；轉換形態：血戟將軍；必要媒介：雙魚玉佩。
- 精神轉力量：`(原精神 - 轉換後精神) × 1.5`。
- 退出形態不覆寫角色基礎精神，因此會自然恢復原精神。
- 理智 = 轉換後精神 × 1.2。
- 120% 時，只有「血淚值歸 0」或「主動退出」依設定觸發下一回合不可行動 + 不可被選中。
- 資源上限會夾在 120，因此不會出現第四階段。

> V1.1 沒有指定「血戟將軍形態的固定精神值」，因此範例將「轉換後精神值」保留為可編輯欄位；一鍵範例預設為 0，可由 DM 改成實際設定。
