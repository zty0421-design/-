# 任務事件自動化總覽｜73-cpp.34.23

本版把 34.22 的結構化任務步驟接上地圖、儀式、Boss 階段與規則引擎事件。

## 自動推進
- `reach_location`：玩家/隊伍真正移動到指定地圖節點時自動完成。
- `perform_ritual`：指定儀式真正進入 `success` 時自動完成。
- `boss_phase`：Boss 進入指定階段時自動完成。
- `rule_event`：規則引擎收到指定事件名稱時自動完成。

## 步驟依賴
- `requires_previous`：必須先完成上一環。
- `depends_on_step_ids`：可額外指定任意前置步驟 ID。
- 玩家手動推進與自動事件都會由 C++ 驗證前置條件。

## 封印任務
`cooperative_seal` 可額外要求：
- 指定 NPC 與玩家同一節點。
- 指定詭異/怪物仍在可封印狀態。
- 至少已安插 N 個任務錨點。
- 指定儀式已在房間中成功完成。

因此可建立「調查 → NPC 會合 → 3 個不同區域安插錨點 → 完成儀式 → 與 NPC 一起封印詭異」的完整流程。
