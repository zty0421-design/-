# 65-cpp.26.8 DM 助手

## 身分

DM 助手仍是一般玩家；`is_admin` 維持 false，以獨立的 `is_dm_assistant` 控制建立資料權限。正式 DM 可以在帳號管理中啟用或取消此身分。

## 可以做

- 新增商店道具。
- 新增裝備／武器商品。
- 新增技能模板。
- 新增合成配方。

所有建立動作會寫入 `dm_assistant_activity` 稽核紀錄。

## 不可以做

- 修改或刪除既有資料。
- 查看 DM 的 NPC 設定、怪物卡與規則怪談管理內容。
- 發放玩家道具、裝備或財貨。
- 修改玩家角色資料。
- 呼叫 `/api/admin/...` 管理 API；這些 API 仍要求 `is_admin=true`。

## 安全模型

限制由 C++ 後端白名單 API 強制執行，不只依賴前端隱藏。撤銷 `is_dm_assistant` 後，下一次操作即會被拒絕，不需要重新建立帳號。
