# 73-cpp.34.25.17 手機效能與按需載入

- 角色卡依目前分頁載入：總覽/屬性只補身份資料，技能才補技能模板，裝備才補詞條系統，背包/狀態才補道具模板。
- 遊戲間依大廳、書庫、命隙分開載入，避免每次進頁同時請求商店、魔法/儀式、知識商店與命運資料。
- 手機玩家頁快取 TTL 提高到 30 秒；桌機 15 秒。切頁後舊請求透過 generation 機制不能覆蓋新畫面。
- 已有快取時背景刷新不顯示全頁載入提示，減少閃爍與重繪。
- 手機/粗指標裝置關閉大型卡片 blur/backdrop-filter 與陰影，並使用 touch-action: manipulation。
