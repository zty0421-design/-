## 64-cpp.25 角色正式等階／登階與登神
- 角色正式採 `0～10階`，每個大階分 `1～4級`。
- 9階為偽神、9階4級為半神、10階為真神。
- 0→1 不需要儀式；其餘跨大階必須先到本階4級，再完成對應登階／登神儀式。
- 固定大階基礎屬性總額：`0/50/100/180/320/600/1100/2000/3600/6500/10000`。
- 可分配五項：敏捷、力量、體質、精神、大道／神明；幸運為不可自由加點的特殊屬性。
- 衍生值：HP=`體質×2`、耐力=`floor((體質+精神)/2)`、理智=`floor(精神×1.2)`、意志=`floor(精神×0.8)`。
- 跨階成功後保留已分配基礎屬性，依新大階總額自動補足剩餘點數。
- 舊任務 `attribute_points` 獎勵不再增加大階總額，任務完成後會重新校正剩餘點數。
