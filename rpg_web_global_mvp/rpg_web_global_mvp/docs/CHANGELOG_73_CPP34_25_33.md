# 73-cpp.34.25.33｜紙本清單第十一批

## 遊戲群

- 新增跨房間持久 `game_groups`、`game_group_members`、`game_group_messages`。
- 玩家可以建立遊戲群、以邀請碼加入、查看成員、留下群組訊息、退出群組。
- 群主可以修改名稱／簡介與刪除群組。
- 只有群組成員可讀取成員與留言；群主修改／刪除權限由 C++ 後端再次驗證。
- 遊戲群不依附單一跑團房間，因此更換房間後仍保留。

## 載入／渲染優化

- `state.gameGroups` 預設為 `null`，登入與進房不自動請求遊戲群 API。
- 玩家展開世界區的遊戲群並按「載入我的遊戲群」後才讀清單。
- 成員與最近留言只有選取某一群後才讀取。
- 每群只回傳最近 50 則留言，避免長群聊一次建立過大的 DOM。
- 手機版群組列表改為緊湊雙欄，留言容器限制高度並獨立捲動。
