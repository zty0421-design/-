# 可成長性裝備總覽｜65-cpp.26.14

## 核心
- 武器與裝備可個別啟用 `growth_enabled`。
- 成長進度由 C++ 保存於 `affix_targets.data`，角色卡中的裝備資料只保留基礎設定。
- 同步角色卡不會把裝備 XP／等級重設成 Lv.1。

## 成長數值
- 等級：`growth_level / growth_max_level`。
- 升級需求：`growth_xp_base + growth_xp_step × (目前等級 - 1)`。
- 每次使用裝備或使用該裝備授予的技能，可取得 `growth_xp_on_use`。
- DM 可由角色編輯器直接給任意正數成長 XP。

## 品階與詞條
- 可設定基礎品階、最高品階與每幾次升級提升一個品階。
- 可設定每幾次升級增加一般詞條容量，以及每次增加多少槽位。
- 新解鎖的一般詞條槽若存在可用詞條池，C++ 會自動抽出新詞條；既有詞條不會被覆蓋。

## 技能成長
- 裝備期間授予的技能使用 `gear_<技能模板ID>`。
- C++ 會驗證玩家目前確實裝備該來源，才允許施放。
- 每級可設定技能傷害百分比成長；最終倍率由 C++ 注入戰鬥核心。
- 裝備原本的指定技能傷害倍率與成長倍率可共同作用。

## 介面
- 玩家：裝備、武器、詞條卡會顯示 Lv、XP 進度、目前品階、詞條槽加成與傷害倍率。
- DM：建立武器／裝備時可設定完整成長規則，並能在角色編輯器直接給成長 XP。
- 手機版：成長設定與 XP 操作維持響應式卡片與大觸控區。
